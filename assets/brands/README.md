# Avanta Systems — Brand Assets

The monochrome SVG marks in this folder were generated from the Simple Icons 14.9.0 font distributed with TeX Live. Simple Icons publishes its collection under CC0, but its legal disclaimer makes clear that trademark rights in individual brand marks are not waived.

The site uses these marks only to identify technologies with which Avanta Systems works. They are not presented as partners, authorized distributors, sponsors, or endorsers.

Before using any mark in a different commercial context, review the applicable brand owner guidelines. In particular, Ubiquiti’s current trademark guidance requires care around logo use and affiliation.

Source project: https://github.com/simple-icons/simple-icons


## Website visual update — September 2026

The site was redesigned to remove the repeated synthetic server-room imagery from the service and sector sections. Those sections now use an editorial, CSS-based visual system with grids, typography, lines and structured content. This avoids relying on repeated stock/AI-looking backgrounds.

The hero is also now a static technology-operations composition built with CSS rather than a carousel of repeated generated images.

The site currently references no files from `assets/img/`; the former image set was removed from this package.
